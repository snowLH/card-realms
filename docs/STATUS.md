# Estado verificável do projeto

## Pronto nesta versão

- Ciclo jogável local: mapa → região → batalha → energia → dado → dano/recompensa.
- Sete tipos originais e nenhuma substituição pelo sistema provisório de cinco tipos.
- Folclore global preservado na identidade, nas regiões e na origem narrativa das criaturas.
- Seis cartas de criatura em combate, com uma ativa e cinco substitutas.
- Cartas de energia fora das seis vagas.
- 25 criaturas completas no código, com nome, lore, origem, região, raridade, função, atributos e três ataques.
- Versão móvel inspecionada em viewport de 390 × 844 pixels.
- Banco preparado com RLS, contas, coleção, equipes, exploração, amizades, casas, caixas, missões, eventos e partidas.
