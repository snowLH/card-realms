# Fontes de arte

Os PNGs fx, props, ui e world são fontes originais ImageGen produzidas para Folklard neste trabalho, usando a direção da Naturalista/v5. Não são assets extraídos de jogos ou imagens de terceiros. O pack world é a revisão com transparência preservada.

Direção de lote: pixel art 2D; contorno escuro em degraus; luz superior; paleta Folklard; famílias coerentes por bioma; fundo transparente; grade 8×8, sem texto/rótulos; telegraphs legíveis e espaço limpo para leitura do combate. FX inclui warning/danger de Camelot/raízes/água, Ward, partículas, corrupção e purificação. Props inclui Guilda, salas, chão, sombras e quatro estados de portal. UI inclui ícones, painéis, botões, HP e minimapa. World inclui tiles de três biomas, cinco estados de portas, projéteis, feixes e áreas.

Os nomes de frames e limites de recorte revisados estão no manifesto/exporter. O arquivo de hashes permite verificar as fontes usadas. Não usar um screenshot de QA como fonte nem pintar uma textura em runtime.

Os seis SVGs em refuge preservam a mobília original do commit 018df58. São apenas fontes offline para exportação WebP; nenhum SVG é montado no navegador.
